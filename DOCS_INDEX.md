# Documentation Index

This index is the canonical map of documentation for the repository.
All docs live at the repository root or under `docs/`.

## Root Documents
- `README.md` — entry point, quickstart, and feature overview.
- `PROJECT_OVERVIEW.md` — intent, goals, constraints, and non-goals.
- `ARCHITECTURE.md` — system components and data flow.
- `CONTRIBUTING.md` — contributor workflow and expectations.
- `STYLE_GUIDE.md` — Python style, naming, and docstring guidance.
- `TESTING.md` — test strategy and how to run tests.
- `PERFORMANCE.md` — performance targets and profiling workflow.
- `CHANGELOG.md` — human-readable project changes.
- `ROADMAP.md` — planned revision milestones.
- `MAINTENANCE.md` — maintenance and release practices.
- `SECURITY.md` — vulnerability reporting policy.
- `CODE_OF_CONDUCT.md` — contributor behavior expectations.
- `GOVERNANCE.md` — decision-making process.
- `DECISIONS.md` — architectural decision log (ADR).

## Docs Folder
- `docs/README.md` — docs landing page and structure guide.
- `docs/benchmarks.md` — benchmark methodology and results.
- `docs/examples.md` — curated examples list with outputs.
- `docs/api.md` — public API overview and stability notes.

## Key Supporting Assets
- `examples/README.md` — walkthrough for example scripts.
- `benchmarks/outputs/` — raw benchmark logs.
- `Results/` — generated example outputs.
- `wordcloud_config.example.json` / `wordcloud_config.example.yaml` — configuration samples.
