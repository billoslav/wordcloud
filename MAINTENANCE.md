# Maintenance

## Releases
- Use semantic versioning when releases are created.
- Update `CHANGELOG.md` for each release.
- Tag releases with a short summary of changes.

## Dependency Policy
- Keep optional dependencies optional.
- Prefer minimal versions that are widely supported.
- Avoid adding large dependencies without a clear feature requirement.

## Deprecations
- Deprecate with clear warnings and a documented replacement.
- Provide at least one release cycle before removal.

## Support Window
- Support the last two minor Python versions where feasible.
