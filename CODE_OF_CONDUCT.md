# Code of Conduct

We are committed to a welcoming, inclusive, and harassment-free environment.

## Expected Behavior
- Be respectful and considerate.
- Assume good intent and communicate clearly.
- Accept constructive feedback gracefully.

## Unacceptable Behavior
- Harassment, discrimination, or hostility.
- Personal attacks or intimidation.
- Publishing private information without consent.

## Reporting
Report issues privately to the project maintainer. If no private channel is
available, open a minimal issue describing the concern.
